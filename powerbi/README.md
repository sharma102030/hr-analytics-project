# Power BI Dashboard

`data/hr_analytics_for_bi.csv` is a cleaned, analysis-ready export of the same dataset used
everywhere else in this project — with `TenureBand`, `IncomeBand`, `AgeGroup`, and `RiskLevel`
columns already computed so you can start building visuals immediately.

**Start here:** [`DASHBOARD_GUIDE.md`](./DASHBOARD_GUIDE.md) — exact steps, DAX measures, and a
visual-by-visual build plan for Power BI Desktop (free), with a short Tableau equivalent at the
end if you'd rather use that instead.

I can't ship a working `.pbix`/`.twbx` file directly — those formats need the actual desktop
app to create — so this is the next best thing: a ready dataset plus copy-pasteable steps that
get you to the same dashboard in well under an hour.
